# 🚀 Habit Tracker

A simple and responsive habit tracking web app built with **React**, **React Router**, and **Tailwind CSS**. Track your daily habits, mark them as done, and monitor your progress over time — all data is saved locally in your browser.

## ✨ Features
- ✅ Add, view, and delete daily habits
- ✅ Mark habits as done/undone with a single click
- ✅ Persistent data storage using `localStorage`
- ✅ Statistics page with live completion percentage
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Client-side routing with React Router (no page reloads)

## 🛠️ Tech Stack
- **React** (Vite)
- **React Router DOM** — for client-side routing
- **Tailwind CSS** — for styling and responsive design
- **localStorage** — for persisting habit data
